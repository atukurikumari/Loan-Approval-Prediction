# Loan Approval Prediction

## Project Overview
This project uses machine learning to predict loan approval based on borrower information.

## Objectives
- Clean and preprocess the dataset.
- Handle missing values and categorical variables.
- Address class imbalance using class weights.
- Compare Logistic Regression, Decision Tree, and Random Forest.
- Evaluate models using Precision, Recall, F1-score, and ROC-AUC.
- Interpret results for business decision-making.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Loan Approval Prediction Case Study dataset from Kaggle.

## Project Workflow
1. Load and explore the dataset.
2. Handle missing values.
3. Encode categorical variables and scale numerical features.
4. Train and compare machine learning models.
5. Evaluate model performance.
6. Select a classification threshold using validation data.
7. Interpret results and save predictions.

## How to Run
1. Download or clone this repository.
2. Install the required packages:
   `pip install pandas numpy matplotlib scikit-learn`
3. Update the dataset path in the Python script.
4. Run the script in a Python environment with access to the dataset.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Disclaimer
This project is for educational purposes. Predictions should not be used as the sole basis for lending decisions.
